Path Length Difference

定义

当两列相干波（频率相同、相位关系恒定）分别从两个波源出发，到达空间中同一点时，它们各自走过的路径长度一般不同。这两段路程之差，称为波程差（path length difference），记作 $\Delta L$：

$$\Delta L = |L_2 - L_1|$$

其中 $L_1, L_2$ 分别是波源 $S_1$、$S_2$ 到观察点 $P$ 的距离。波程差决定了两列波到达 $P$ 点时的相位关系，从而决定发生相长干涉（constructive interference，振幅叠加增强）还是相消干涉（destructive interference，振幅相互抵消）。

判据基于波长 $\lambda$：

$$\Delta L = m\lambda \quad (m = 0, 1, 2, \dots) \;\Rightarrow\; \text{相长干涉（波峰对波峰）}$$ $$\Delta L = \left(m + \tfrac{1}{2}\right)\lambda \quad (m = 0, 1, 2, \dots) \;\Rightarrow\; \text{相消干涉（波峰对波谷）}$$

这是因为波程差每相差整数个波长，两列波便重新同相；每相差半个波长的奇数倍，两列波便刚好反相。

例题

两个扬声器 $S_1$、$S_2$ 相距 $2\text{ m}$，同相发出频率为 $340\text{ Hz}$ 的声波，声速 $v = 340\text{ m/s}$，故 $\lambda = v/f = 1\text{ m}$。观察点 $P$ 到 $S_1$ 的距离为 $5.0\text{ m}$，到 $S_2$ 的距离为 $6.0\text{ m}$。

$$\Delta L = |6.0 - 5.0| = 1.0\text{ m} = 1 \times \lambda$$

由于 $\Delta L$ 恰为一个整波长，$m=1$，故 $P$ 点发生相长干涉，该处声音明显增强。

解题应用

在双缝干涉实验中，若两缝间距为 $d$，屏幕距双缝为 $D$（$D \gg d$），观察点在屏上偏离中心轴 $y$ 处，则波程差可用几何近似求得：

$$\Delta L \approx \frac{d y}{D}$$

将此式代入相长干涉条件 $\Delta L = m\lambda$，即可解出亮纹位置：

$$y_m = \frac{m \lambda D}{d}$$

解题时的通用步骤：先分别计算两条路径的几何长度，求出 $\Delta L$；再将 $\Delta L$ 表示为 $\lambda$ 的倍数（即 $\Delta L / \lambda$）；最后根据该比值是否为整数或半整数，判断干涉类型。这一方法同样适用于分析薄膜干涉、迈克尔逊干涉仪等场景，只是在计算 $\Delta L$ 时需额外考虑介质折射率或反射相位跃变（如半波损失）带来的修正。
