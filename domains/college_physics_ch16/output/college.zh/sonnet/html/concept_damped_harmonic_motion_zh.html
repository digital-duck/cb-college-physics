Damped Harmonic Motion

定义

理想的简谐运动假设系统不受能量损耗，振幅永远保持不变。但现实中的振子——无论是汽车悬架、钟摆还是分子振动——都会受到摩擦力、空气阻力或电阻等非保守力的作用，这些力持续地从系统中带走能量，使振幅随时间衰减。这种运动称为阻尼谐振动。

若阻尼力与速度成正比（$F_{damp} = -bv$，其中 $b$ 为阻尼系数），牛顿第二定律给出运动方程：

$$m\ddot{x} + b\dot{x} + kx = 0$$

将其改写为标准形式，定义 $\omega_0 = \sqrt{k/m}$（无阻尼时的自然角频率）和 $\gamma = b/(2m)$（阻尼率），方程变为：

$$\ddot{x} + 2\gamma\dot{x} + \omega_0^2 x = 0$$

这是一个二阶线性常微分方程，其特征方程为 $r^2 + 2\gamma r + \omega_0^2 = 0$，解得：

$$r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}$$

判别式的符号决定了三种运动类型：欠阻尼（$\gamma < \omega_0$，振荡衰减）、过阻尼（$\gamma > \omega_0$，无振荡缓慢趋于零）、临界阻尼（$\gamma = \omega_0$，最快趋于平衡且不振荡）。

推导与求解

在欠阻尼情形下，解具有振荡衰减的形式：

$$x(t) = A e^{-\gamma t}\cos(\omega_d t + \phi)$$

其中 $\omega_d = \sqrt{\omega_0^2 - \gamma^2}$ 是阻尼后的振荡频率，$A$、$\phi$ 由初始条件确定。注意 $\omega_d < \omega_0$：阻尼不仅使振幅衰减，还降低了振荡频率。

问题求解应用

一个质量 $m = 0.5\text{ kg}$ 的振子，弹簧常数 $k = 8\text{ N/m}$，阻尼系数 $b = 2\text{ kg/s}$。求其运动类型及衰减后的频率。

先计算 $\omega_0 = \sqrt{8/0.5} = 4\text{ rad/s}$，$\gamma = 2/(2\times0.5) = 2\text{ rad/s}$。由于 $\gamma < \omega_0$，系统欠阻尼。阻尼频率为：

$$\omega_d = \sqrt{4^2 - 2^2} = \sqrt{12} \approx 3.46\text{ rad/s}$$

振幅按 $e^{-2t}$ 衰减，经过 $t = 1/\gamma = 0.5\text{ s}$ 后振幅降为初始值的 $1/e \approx 37\%$——这段时间称为系统的时间常数，是判断阻尼强弱的实用指标。工程设计中（如悬架系统），常通过调节 $b$ 使系统接近临界阻尼，以兼顾快速回复平衡与避免持续振荡。
