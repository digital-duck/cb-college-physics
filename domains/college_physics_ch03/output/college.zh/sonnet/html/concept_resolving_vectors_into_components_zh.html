将向量分解为分量

定义

向量分解是指将一个向量沿两个（或更多）互相垂直的方向拆分，使得这些分量的合成恰好等于原向量。在二维空间中，我们通常选取水平方向（$x$ 轴）和竖直方向（$y$ 轴）作为分解的基准。若向量 $\vec{v}$ 的大小为 $|\vec{v}|$，与正 $x$ 轴的夹角为 $\theta$，则其分量为：

$$v_x = |\vec{v}|\cos\theta, \qquad v_y = |\vec{v}|\sin\theta$$

反之，已知分量可还原大小与方向：

$$|\vec{v}| = \sqrt{v_x^2 + v_y^2}, \qquad \theta = \arctan\!\left(\frac{v_y}{v_x}\right)$$

例题

一名足球运动员以 $20\ \text{m/s}$ 的速度踢出一球，方向与地面成 $35°$ 角。求水平分速度和竖直分速度。

$$v_x = 20\cos 35° \approx 20 \times 0.819 = 16.4\ \text{m/s}$$ $$v_y = 20\sin 35° \approx 20 \times 0.574 = 11.5\ \text{m/s}$$

这两个分量相互独立：$v_x$ 决定球的水平位移，$v_y$ 决定球能飞多高。正是这种"拆解"让我们可以分别用匀速直线运动和竖直抛体运动来分析同一个球的运动。

解题应用

向量分解的真正价值在于化繁为简。考虑一个更复杂的情境：三个力同时作用于一个物体：$\vec{F}_1 = 50\ \text{N}$（朝正东）、$\vec{F}_2 = 30\ \text{N}$（朝北偏东 $60°$）、$\vec{F}_3 = 20\ \text{N}$（朝正北）。求合力。

将每个力分解：

| 力 | $x$ 分量（东） | $y$ 分量（北） | |---|---|---| | $\vec{F}_1$ | $50$ N | $0$ N | | $\vec{F}_2$ | $30\cos60°=15$ N | $30\sin60°\approx 26.0$ N | | $\vec{F}_3$ | $0$ N | $20$ N | | 合计 | 65 N | 46.0 N |

合力大小：

$$|\vec{F}| = \sqrt{65^2 + 46^2} \approx \sqrt{4225 + 2116} = \sqrt{6341} \approx 79.6\ \text{N}$$

方向：$\theta = \arctan(46/65) \approx 35.3°$（偏北方向）

这种"逐列求和"的策略是物理和工程中处理多向量叠加的标准方法——只要学会分解，任意多个方向杂乱的向量都可以被整合为一个清晰的合量。
