结果向量

定义

结果向量（resultant vector）是两个或多个向量相加后所得的单一向量，它等效地代表了所有分量向量的综合效果。在物理和工程中，当多个力、速度或位移同时作用时，我们不需要逐一追踪每一个，只需求出它们的结果向量即可描述系统的整体行为。

若有两个向量 $\vec{A} = (A_x,\, A_y)$ 与 $\vec{B} = (B_x,\, B_y)$，其结果向量为：

$$\vec{R} = \vec{A} + \vec{B} = (A_x + B_x,\; A_y + B_y)$$

结果向量的大小（模）与方向分别为：

$$|\vec{R}| = \sqrt{R_x^2 + R_y^2}, \qquad \theta = \arctan\!\left(\frac{R_y}{R_x}\right)$$

例题

一艘船以 $\vec{v}_1 = (4,\; 3)\ \text{m/s}$ 向东北方向行驶，同时水流以 $\vec{v}_2 = (-1,\; 2)\ \text{m/s}$ 施加影响。求船的实际速度向量。

$$\vec{R} = \vec{v}_1 + \vec{v}_2 = (4 + (-1),\; 3 + 2) = (3,\; 5)\ \text{m/s}$$

实际速度的大小：

$$|\vec{R}| = \sqrt{3^2 + 5^2} = \sqrt{34} \approx 5.83\ \text{m/s}$$

方向角（相对于正东方向）：

$$\theta = \arctan\!\left(\frac{5}{3}\right) \approx 59.0°$$

因此，船实际以约 $5.83\ \text{m/s}$ 的速度朝北偏东 $59°$ 方向前进。

解题应用

在实际问题中，已知条件常以大小和角度给出，而非分量形式。解题步骤如下：

  • 将每个向量分解为水平分量（$\cos\theta$）和竖直分量（$\sin\theta$）；
  • 分别对所有水平分量和竖直分量求和，得到 $R_x$ 与 $R_y$；
  • 用上述公式计算结果向量的大小和方向。

    • 例如，一个人同时受到三个力的作用：$60\ \text{N}$ 向东、$80\ \text{N}$ 向北、$40\ \text{N}$ 朝西南方向（$225°$）。先分解第三个力：$F_{3x} = 40\cos225° \approx -28.3\ \text{N}$，$F_{3y} = 40\sin225° \approx -28.3\ \text{N}$。汇总后得 $R_x \approx 31.7\ \text{N}$，$R_y \approx 51.7\ \text{N}$，结果向量大小约为 $61.0\ \text{N}$，方向约为北偏东 $58.5°$。

    掌握结果向量的求法是分析受力平衡、抛体运动和导航问题的核心基础。
