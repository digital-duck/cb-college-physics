力常数

在胡克定律 $F = -kx$ 中，力常数 $k$（也称劲度系数）描述了一个弹性系统抵抗形变的能力：位移 $x$ 越大，恢复力 $F$ 就越大，而 $k$ 正是这种比例关系的量化系数，单位是牛顿每米（$\mathrm{N/m}$）。$k$ 越大，系统越"硬"，产生单位位移所需的力就越大；$k$ 越小，系统越"软"，容易发生形变。需要注意的是，$k$ 并非材料的固有属性，而是特定弹簧或系统的属性——同种材料做成粗细、长短不同的弹簧，$k$ 值也会不同。

定义与推导

对于理想弹簧，$k$ 可由实验测定：给弹簧施加已知力 $F$，测量其伸长量 $x$，则

$$k = \frac{F}{x}$$

若在弹性极限内多次测量并作 $F$–$x$ 图，图像应为过原点的直线，其斜率即为 $k$。这也是胡克定律成立的判据：只要图像保持线性，系统就处于"弹性区"；一旦偏离直线，说明材料已发生塑性形变，胡克定律不再适用。

例题

一根弹簧在悬挂 $2.0\,\text{kg}$ 砝码后伸长了 $0.050\,\text{m}$。求该弹簧的力常数。

取 $g = 9.8\,\text{m/s}^2$，恢复力等于重力：

$$F = mg = (2.0)(9.8) = 19.6\,\text{N}$$ $$k = \frac{F}{x} = \frac{19.6}{0.050} = 392\,\text{N/m}$$

应用：弹簧组合

工程中常需将多个弹簧组合使用。若两弹簧并联（共同承担同一位移），等效力常数为

$$k_{\text{eq}} = k_1 + k_2$$

若两弹簧串联（力相同，位移叠加），则

$$\frac{1}{k_{\text{eq}}} = \frac{1}{k_1} + \frac{1}{k_2}$$

例如，两根 $k_1 = 200\,\text{N/m}$ 与 $k_2 = 300\,\text{N/m}$ 的弹簧并联，$k_{\text{eq}} = 500\,\text{N/m}$；若串联，则 $k_{\text{eq}} = 120\,\text{N/m}$。这类计算在悬架系统、减震器设计等实际问题中十分常见，也是理解简谐振动周期 $T = 2\pi\sqrt{m/k}$ 的基础——$k$ 越大，系统振动越快，恢复能力越强。
