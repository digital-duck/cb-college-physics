Object Distance

定义

物距（object distance）$d_o$ 是指物体到透镜或反射镜中心（或光心）的距离，通常沿主光轴测量，单位为米（m）或厘米（cm）。物距是薄透镜方程和反射镜方程中的核心变量之一，与像距 $d_i$、焦距 $f$ 共同满足：

$$\frac{1}{d_o} + \frac{1}{d_i} = \frac{1}{f}$$

按照惯例（笛卡尔符号约定），实物的物距取正值，即光线从物体出发、朝透镜或镜面传播的一侧，$d_o > 0$。物距的大小直接决定了成像的位置、大小和虚实性质，因此准确测量或给定 $d_o$ 是求解几何光学问题的第一步。

例题

一个焦距 $f = 10\text{ cm}$ 的凸透镜前方 $d_o = 15\text{ cm}$ 处放置一个物体，求像距 $d_i$。

代入透镜方程：

$$\frac{1}{15} + \frac{1}{d_i} = \frac{1}{10}$$ $$\frac{1}{d_i} = \frac{1}{10} - \frac{1}{15} = \frac{3 - 2}{30} = \frac{1}{30}$$ $$d_i = 30\text{ cm}$$

由于 $d_i > 0$，像为实像，成在透镜另一侧 $30\text{ cm}$ 处。

解题应用

在实际问题中，物距常常是唯一已知的自变量，题目要求你判断像的性质（实像/虚像、放大/缩小、正立/倒立）会如何随 $d_o$ 变化。关键的判断技巧是比较 $d_o$ 与焦距 $f$ 的相对大小：

  • 当 $d_o > 2f$：成缩小、倒立的实像；
  • 当 $f < d_o < 2f$：成放大、倒立的实像；
  • 当 $d_o < f$：透镜方程给出 $d_i < 0$，即物体在焦点以内，成正立、放大的虚像（如放大镜的工作原理）。

    • 解题时，先明确物距的符号约定和取值范围，再代入透镜/镜面方程求解未知量，最后通过横向放大率 $m = -d_i/d_o$ 验证像的大小与朝向是否与预期的物理图像一致。这种“先定性判断、再定量计算、最后交叉验证”的顺序，能有效避免符号错误导致的物理意义误判。
